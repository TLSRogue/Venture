# Sound Effects Guide

Add your `.mp3`, `.wav`, or `.ogg` sound files to this folder with the following names:

## Combat Sounds

| Filename       | Description              | Recommended Duration | Status |
| -------------- | ------------------------ | -------------------- | ------ |
| `hit.mp3`      | Weapon/attack hit sound  | 0.2-0.5s             | ❌     |
| `miss.mp3`     | Attack miss/whoosh sound | 0.2-0.4s             | ❌     |
| `critical.mp3` | Critical hit sound       | 0.3-0.6s             | ❌     |
| `block.mp3`    | Shield block sound       | 0.2-0.4s             | ❌     |
| `parry.mp3`    | Parry/deflect sound      | 0.2-0.4s             | ❌     |
| `punch.wav`    | Punch spell sound        | 0.2-0.5s             | ✅     |

## Tips

- Keep files small (< 100KB each) for quick loading
- Use MP3 format for best browser compatibility
- Normalize audio levels so sounds aren't jarring
- Short, punchy sounds work best for game feedback
